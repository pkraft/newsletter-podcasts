Anthropic has launched something called Claude Ship. It is currently in beta. The idea is to let AI agents review, fix, and approve pull requests. Without a human. It pairs their existing code review feature with two new agents. The first is PR Steward. If tests fail, or if a human reviewer leaves correction notes, this agent reworks the pull request itself. The second is Claude Approvals. It checks a policy file in the project directory. It decides whether it can sign off on a routine change alone. Or whether it must defer to a person. With GitHub’s auto-merge setting on, and the right policy in place, Anthropic’s documentation says code can go from change to merged pull request. With no human involved at any step. The feature is only available on Team and Enterprise plans. It is billed separately by token use. PR Steward carries no spending cap by default, unless a team sets one. Why it matters. In March, Anthropic’s tool only flagged bugs for a person to act on. This one can act on its own findings. And then approve its own fix. That is a real step past assisting a software team. And into running part of its workflow unsupervised. Not ideal. But here we are. This information comes from The Decoder, and from Anthropic’s own announcement. ...
