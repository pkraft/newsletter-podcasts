Visa has open-sourced a tool. It is called the Vulnerability Agentic Harness. Or VVAH, if you prefer the initials. It is an expanded version of something they had before. It is built on lessons from Anthropic's Project Glasswing. A defensive security initiative. This new version is a pipeline. Four phases. Eleven stages. It does more than just find bugs. Specifically, the security architecture. Ninety-three contributors worked on this. Wait. That feels low for such a massive project. Let me check my memory. Ah, no. The release overhauls how agents handle sensitive access. This is the important part. There are now masked credential requests. These never expose secret values in the chat history. You cannot see the password. You cannot accidentally leak it to a stranger. There is a shared team credential store. It has an optional integration with 1Password. If you are using that, fine. If not, you are on your own. There is mandatory capability disclosure. Before you install external plugins, the system tells you what it wants to do. It has to ask permission. No more sneaky business. And there are workspace restrictions. Filesystem access is anchored to approved directories. If the agent wants to go elsewhere, it has to ask. It also ships a rebuilt browser app. And multiplayer sessions. I suppose agents can now play together. How novel. Why does this matter? OpenClaw’s scale of community contribution makes it a bellwether. It shows how the open-source agent ecosystem is responding. We have had a summer of agent-related security incidents. At open A-I. At Meta. And elsewhere. The industry is treating credential and plugin handling as the attack surface that actually matters. It seems logical. If you protect the keys, you protect the house.
