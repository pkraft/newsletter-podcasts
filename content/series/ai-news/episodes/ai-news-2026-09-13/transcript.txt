Security startup Accomplish has disclosed a problem. They call it Beltdown. It is a sandbox escape in Claude Code. An untrusted Git repository could run commands on a user's Mac. Outside the sandbox. With no permission prompt. It worked by abusing Git's core dot F-S-monitor setting. It used an unhardened file-listing command. And a gap in how the sandbox handled nested dot Git folders. Accomplish reported related escapes in Cursor and open A-I's Codex around the same time. Cursor and open A-I shipped fixes within about a week. Anthropic took from its July thirteenth report to an August twenty-sixth full patch. Roughly six weeks. And two partial releases. To fully close the Claude Code hole.
